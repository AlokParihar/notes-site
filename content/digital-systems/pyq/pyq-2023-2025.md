## Exam pattern (consistent across all papers)

- **Total questions:** 8, attempt any 5
- **Marks:** 70, Time: 3 hours
- **Format:** bilingual (English + Hindi)
- Number system conversions (Q1) are a near-guaranteed opener in every paper — practice binary/octal/hex/BCD/Excess-3/Gray code conversions until they're mechanical
- Several questions include circuit diagrams (e.g. address mapping, logic circuits) that don't reproduce well as plain text — where a paper references "Fig. 1/2/3" etc., the diagram itself isn't included here; treat those as a reminder to check the original PDF for the visual

**Takeaway:** Flip-flops and number system conversions are the most reliable — near-certain in every paper. Unit 5 (digital communication) is tested lightly but consistently across recent papers, usually as one dedicated question rather than spread across several — worth knowing PCM and sampling theorem cold since it's a concentrated, predictable ask.

## December 2025

**Q1.**

(a) Convert the following: (i) (753)₈ to decimal (ii) (4A3)₁₆ to binary (iii) (101101.101)₂ to decimal (iv) (45.625)₁₀ to Binary (v) (110101101)₂ to Hexadecimal (vi) (74)₁₀ to Excess-3 code (vii) (11011101)₂ to Gray code.

(b) Simplify the following function using 3-variable K-map: F(A,B,C)=Σm(1,2,3,5,7). Also draw the simplified logic diagram.

**Q2.**

(a) Implement the Boolean function using only NAND gates: F(A,B,C)=AB+A'C.

(b) Explain the working of a Full Adder with truth table and logic diagram. Why is it required in arithmetic circuits?

**Q3.**

(a) Implement the Boolean function F(A,B,C)=Σm(1,3,6,7) using a 4:1 multiplexer.

(b) Design a decimal-to-BCD encoder and explain its working.

**Q4.**

(a) Explain the working of a Master–Slave J-K flip-flop with timing diagram.

(b) Explain asynchronous counters and synchronous counters. Compare them with respect to speed and hardware complexity.

**Q5.**

(a) Implement the Boolean functions using PLA: F1=A'B+AC, F2=AB+BC'. Draw the PLA programming table.

(b) Explain the working of a Sample and Hold circuit with neat diagram. Why is it required in ADC systems?

**Q6.**

(a) Explain the internal block diagram and working of IC 555 Timer. Discuss any two applications of IC 555.

(b) Explain the need for interfacing between TTL and MOS logic. Discuss TTL-to-CMOS interfacing techniques.

**Q7.**

(a) Explain Time Division Multiplexing (TDM) with block diagram. Differentiate between synchronous and asynchronous TDM.

(b) Explain quantization process and quantization error in PCM. How can quantization noise be reduced?

**Q8.** Write a short note on any two: Logic Gates · Look-ahead carry generator · S-R Flip-Flop · Shannon's Channel Capacity Theorem.

## June 2025

**Q1.**

(a) Convert the number (AD)₁₆ into decimal and binary and octal numbers.

(b) Discuss the difference of Binary numbers and BCD code. What is binary number and BCD code for a decimal number (13)₁₀.

**Q2.**

(a) What do you mean by Universal Gates? How to realize AND, OR and NOT functions using universal gates only?

(b) What do you mean by canonical form? Express the Boolean function F = A + B'C in (i) SOP and (ii) POS.

**Q3.**

(a) Draw and discuss the circuit of look-ahead carry generator.

(b) What is the half subtractor circuit? Design a half subtractor circuit and write all the necessary steps of designing.

**Q4.**

(a) Explain how decoders and multiplexers can be used to implement combinational circuits. Draw a half adder circuit with a decoder.

(b) What is a digital multiplexer? Implement a Boolean function F(A,B,C) = Σ(1,3,5,6) with a multiplexer.

**Q5.**

(a) Give a classification of storage devices. Discuss the modern trends in semiconductor memories such as DRAM, FLASH RAM etc.

(b) With the help of circuit diagram explain the working of JK flip-flop. Write its characteristics tables and equations.

**Q6.**

(a) Compare TTL, PMOS, CMOS and NMOS logic families.

(b) Write a note on voltage to frequency and frequency to voltage conversion.

**Q7.**

(a) Draw block diagram of Pulse Code Modulation (PCM) and explain it in detail. What do you mean by quantization error and how to minimize it?

(b) Discuss the need of A/D and D/A convertors. Draw successive approximation analog to digital converter and explain its working in details.

**Q8.** Write a short note on any two: Shannon's theorem for channel capacity · Schmitt trigger · Racing condition · ROM and PLA.
