## Unit 1 — C Review, Intro to DS & Linked Lists

- Review of C programming language
- Data structure concepts: data vs information, classification of data structures, abstract data types
- Memory representation; data structure operations and cost estimation
- Linear data structures — arrays
- Linked lists: memory representation, different implementations, circular linked list, doubly linked list
- Applications of linked lists — e.g. polynomial manipulation

## Unit 2 — Stacks & Queues

- Stacks as ADT, different implementations, multiple stacks
- Applications of stack: infix-to-postfix conversion, evaluation of postfix expression, recursion
- Queues as ADT, different implementations, circular queue
- Deque and priority queue concepts; queue simulation and applications

## Unit 3 — Trees

- Definitions: height, depth, order, degree, etc.
- Binary Search Tree — operations, traversal, search
- AVL Tree, Heap — applications and comparison of tree types
- Introduction to forests, multi-way trees, B-tree, B+ tree, B* tree, red-black tree

## Unit 4 — Graphs

- Introduction to graphs; classification — directed and undirected
- Graph representation; traversal — DFS and BFS
- Graph algorithms: Minimum Spanning Tree (Kruskal's, Prim's), Dijkstra's shortest path
- Comparison between graph algorithms; applications of graphs

## Unit 5 — Sorting & Searching

- Sorting: Bubble, Quick, Selection, Heap, Insertion, Shell, Merge, Radix — comparison of techniques
- Searching: sequential search, binary search, comparison of search methods
- Hashing & indexing
- Case study: application of data structures in OS, DBMS, etc.
