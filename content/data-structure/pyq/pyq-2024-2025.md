## Exam pattern (consistent across all papers)

- **Total questions:** 8, attempt any 5
- **Marks:** 70, Time: 3 hours
- **Format:** bilingual (English + Hindi)
- Trees (BST, AVL) and sorting/searching algorithms appear in almost every single paper — this is the highest-yield area to be rock solid on
- Several questions ask for an algorithm *and* a worked example/trace (e.g. "construct an AVL tree by inserting the following elements") — practice tracing through, not just stating the algorithm

**Takeaway:** Trees (BST + AVL, Unit 3) and linked lists (Unit 1) are the most consistently tested topics — near-guaranteed in every paper. Graph algorithms (MST, Dijkstra's) also show up often but tend to be paired with a "explain with example" ask, so know the trace-through, not just the definition. Sorting/searching comparisons are common short-note fodder.

## December 2025

**Q1.**

(a) Explain the classification of data structures in detail.

(b) Define Abstract Data Types (ADT). Explain the different operations performed on data structures and describe the criteria for cost estimation.

**Q2.**

(a) Describe the memory representation of a Singly Linked List. Write an algorithm to insert a node at a specific position in a linked list.

(b) Define Stack as an ADT. Explain the array and linked list implementation of stacks.

**Q3.**

(a) Explain the algorithm to convert an Infix expression to a Postfix notation using a stack.

(b) Explain the concept of Queue simulation with a real-world example.

**Q4.**

(a) Define a Binary Search Tree (BST). Explain the algorithms for In-order, Pre-order, and Post-order traversal with an example.

(b) What are AVL Trees? Explain the four types of rotations (LL, RR, LR, RL) used to balance an AVL tree.

**Q5.**

(a) Define the following tree terminologies: Height, Depth, Degree of a node, and Forest.

(b) Explain the Adjacency Matrix and Adjacency List representations of a graph.

**Q6.**

(a) Describe the Depth First Search (DFS) and Breadth First Search (BFS) algorithms for graph traversal with examples.

(b) What is a Minimum Spanning Tree (MST)? Explain Kruskal's or Prim's algorithm to find the MST of a weighted graph.

**Q7.**

(a) Explain the Quick Sort algorithm with suitable example.

(b) Explain Binary Search with an example.

**Q8.** Write short notes on any two: Circular Linked Lists · Linear Probing and Chaining · B+ Trees · Dijkstra's shortest path algorithm.

## June 2025

**Q1.**

(a) Describe the difference between an abstract data type specification and implementation.

(b) How is a two dimensional array represented in memory? Calculate amount memory required to store this array and the accessing function for it.

**Q2.**

(a) Give the implementation of circular linked list. Also give its application.

(b) Discuss various classification of data structures with an example.

**Q3.**

(a) What is Stack? Why it is known of LIFO? Write algorithm of PUSH, POP and CHANGE operation on stack.

(b) Write a 'C' program to convert the infix expression to postfix expression.

**Q4.**

(a) Differentiate between the stack and queue.

(b) What are circular queue and priority queue? Write an algorithm in insert and delete an element from a circular queue.

**Q5.**

(a) Explain Red black trees also discuss the properties of red black tree.

(b) Construct an AVL search tree by inserting the following elements in order of their occurrence: 64, 1, 44, 26, 13, 110, 98, 85.

**Q6.**

(a) Explain Dijkstra algorithm with the help of example.

(b) Write a C function to create the adjacency list representation of a graph, given its adjacency matrix representation.

**Q7.**

(a) Write a Heap sort algorithm. Use Heap sort algorithm to sort the following element: 12, 3, 9, 14, 10, 18, 8, 23.

(b) What are hash function? Write down various popular hash function with example.

**Q8.** Write short notes (any three): B-tree · Indexing · Postfix evaluation · Shell sort · Prim's algorithm.

## December 2024

**Q1.**

(a) Write an algorithm for traversing nodes in a single linked list? Explain with an example.

(b) Define data structures. Classify different types of data structures.

**Q2.**

(a) Compare and contrast the characteristics of arrays and linked lists as abstract data types.

(b) Describe the concept of a dynamic array and how it differs from a static array in terms of memory management and flexibility.

**Q3.**

(a) Write an algorithm which reverses the order of elements on stack using one additional stack and some additional variables.

(b) Explain the addition and deletion operations performed on a circular queue with necessary algorithms.

**Q4.**

(a) Write an algorithm for Push and Pop operations on Stack using linked list.

(b) What is a DeQueue? Explain its operation with example.

**Q5.**

(a) Construct an expression tree for the expression (a+b*c) + ((d*e+f)*g). Apply inorder, preorder and postorder traversals on tree.

(b) Create a binary search tree for the following numbers: 45, 26, 10, 60, 70, 30, 40. Start from an empty binary search tree. Delete keys 10, 60 and 45 one after the other and show the trees at each stage.

**Q6.**

(a) Describe the algorithms used to perform single and double rotation on AVL tree.

(b) Differentiate between Depth first search and Breadth First search algorithm.

**Q7.**

(a) Define minimum spanning tree. Write down Prim's algorithm to find minimum spanning tree.

(b) Sort the following elements using quick sort: 55, 72, 12, 45, 88, 38, 27, 33, 91, 80.

**Q8.**

(a) Apply Binary search to search 36 in following list: 21, 12, 36, 32, 38, 23, 56, 83, 92, 5, 10, 15.

(b) Write short notes: Hashing and Indexing · Heap Sort · Red Black Tree.
