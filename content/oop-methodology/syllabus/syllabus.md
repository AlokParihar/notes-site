## Unit 1 — Introduction to Object Oriented Thinking

- Object oriented thinking & OOP — comparison with procedural programming
- Features of the OO paradigm — merits and demerits of OO methodology
- Object model; elements of OOP; I/O processing

## Unit 2 — Encapsulation and Data Abstraction

- Concept of objects: state, behavior, identity
- Classes: identifying classes and candidates for classes; attributes and services
- Access modifiers; static members of a class
- Instances; message passing; construction and destruction of objects

## Unit 3 — Relationships — Inheritance

- Inheritance: purpose and types; "is-a" relationship
- Association, aggregation
- Concept of interfaces and abstract classes

## Unit 4 — Polymorphism

- Method overriding & overloading
- Static and runtime polymorphism

## Unit 5 — Advanced Concepts & Case Studies

- Strings; exception handling
- Introduction to multi-threading and data collections
- Case studies: ATM, Library management system
