## 1. Programming Languages

| Language | Why Learn It? | Key Libraries/Frameworks | Focus |
|---|---|---|---|
| Python | Easy syntax, versatile (web, AI, automation) | NumPy, Pandas, Flask, Django, TensorFlow | Data structures, control flow, functions, modularity |
| Java | Object-oriented, used in Android and enterprise | Spring, Android SDK | OOP concepts, memory management, scalable code |
| C++ | System-level programming, performance-critical | STL, Unreal Engine | Memory management (pointers), low-level optimization |
| JavaScript | Essential for web development, full-stack | React, Angular, Node.js | DOM manipulation, async programming, web APIs |

### OOP concepts worth being sharp on

- **Classes and Objects** — classes define structure, objects are instances
- **Inheritance** — code reuse via hierarchical class relationships
- **Polymorphism** — same method behaving differently (overloading/overriding)
- **Encapsulation** — hiding internal state, exposing only what's needed (private/public, getters/setters)
- **Abstraction** — simplified interface, hiding implementation complexity
- **Design Patterns** — Singleton, Factory, Observer — standardized solutions to recurring problems

## 2. Data Structures & Algorithms

| Topic | Why Important | Common Operations |
|---|---|---|
| Arrays | Contiguous storage, fast indexing | Access, traverse, search, sort |
| Linked Lists | Dynamic allocation, flexible insert/delete | Insert, delete, search, traverse |
| Stacks | LIFO — function calls, expression eval | Push, pop, peek |
| Queues | FIFO — task scheduling, print queues | Enqueue, dequeue, circular queues |
| Trees (Binary, BST) | Hierarchical data, fast search/sort | Insertion, deletion, DFS, BFS |
| Graphs | Networks — social, web, routing | DFS, BFS, Dijkstra's, Bellman-Ford |
| Sorting | Efficient data arrangement | Merge Sort, Quick Sort, Heap Sort |
| Searching | Fast element lookup | Linear, Binary, Hash-based |
| Dynamic Programming | Break complex problems into subproblems | Memoization, tabulation |
| Greedy Algorithms | Locally optimal choices | Resource allocation, Huffman coding, Kruskal's |
| Hashing | Fast retrieval via hash functions | Insert, search, delete in hash tables |
